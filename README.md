# Essence — интернет-магазин концептуальной одежды

Курсовой проект по веб-разработке.

## О проекте
Интернет-магазин одежды в стиле Maison Margiela. Минималистичный дизайн, адаптивная вёрстка, корзина с сохранением в LocalStorage, загрузка товаров из XML.

## Технологии
- HTML5, CSS3, SCSS
- JavaScript (ES6)
- XML для хранения данных
- LocalStorage для корзины
- Адаптивная верстка (Flexbox, Media Queries)

## Структура
- Главная страница с описанием бренда
- Мужская линейка (12 товаров)
- Женская линейка (8 товаров)
- Страница товара с выбором размера
- Корзина с удалением товаров
- Форма регистрации

## Как запустить
1. Скачать репозиторий
2. Открыть `index.html` через Live Server (из-за CORS)
